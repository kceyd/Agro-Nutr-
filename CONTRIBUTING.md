# Cómo trabajamos en equipo (Equipo08)

Para que el repositorio refleje la participación de **todos** los integrantes:

1. `main` es la rama estable: nadie hace commit directo en ella.
2. Cada tarea tiene un **issue** de GitHub asignado a una persona (ej. `#12 Validación de correo`).
3. Se trabaja en una rama propia: `feature/<tema>-<nombre>` (ej. `feature/validacion-sergio`).
4. Commits pequeños y con mensaje claro, hechos desde la cuenta de GitHub de cada integrante:
   `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`.
5. Para unir a `main` se abre un **Pull Request** que cierra el issue (`Closes #12`) y lo revisa
   **otro** integrante antes de hacer merge.
6. Las tareas se mueven en el tablero (GitHub Projects): Por hacer → En curso → En revisión → Hecho.
